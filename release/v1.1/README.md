# 词迹 v1.1：双口音朗读分支

本分支用于隔离测试 HarmonyOS 6 + Chrome 的朗读修复，不影响当前 `main` 生产版本。

## 更新内容

- 131 个单词全部配备英式独立音频，共 131 个 MP3。
- 131 个单词全部配备美式独立音频，共 131 个 MP3。
- 英式模式播放顺序：英式独立音频 → 英式系统语音 → 美式独立音频 → 其他英语系统语音。
- 美式模式采用相反顺序。
- 独立音频支持 0.75×、0.85×、1.0×、1.15×速度。
- 首次自动朗读前需在“设置 → 发音设置”点击“启用并试听 atmosphere”。
- 增加语音诊断，可查看独立音频数量、系统英语语音数量、实际朗读来源及首次播放权限。
- 增加“发音失败提示”开关。
- 新版词包会自动为已有 131 词补充音频地址，不清除学习记录。
- 262 个音频加入 PWA 离线缓存。
